# KI-Consulting für Schweizer KMU — Service-Angebot

> **Drei Stufen. Ein Ziel: Ihr Wissen strukturieren, Ihre KI zum Laufen bringen.**

---

## 🚀 Stufe 1: KI-Wissens-Check — CHF 750

*Einstieg ohne Risiko. Wird bei Beauftragung voll angerechnet.*

| Was Sie bekommen | |
|-------------------|---|
| Analyse Ihrer aktuellen Daten- und Prozesslandschaft | 1 Tag |
| Gespräch mit den Entscheidern (1–2h) | Inklusive |
| Identifikation der grössten Automatisierungs-Potenziale | Priorisierte Liste |
| Konkreter, priorisierter Aktionsplan | Schriftlicher Report |
| **CHF 750 werden bei Projektstart voll angerechnet** | **→ Faktisch kostenlos** |

**Ideal für:** Unternehmen, die wissen wollen, ob KI bei ihnen überhaupt etwas bringt — ohne gleich tief in die Tasche zu greifen.

---

## 🛠️ Stufe 2: Knowledge Base (Core) — CHF 3,500–4,500

*Ihr strukturierter Wissensspeicher, den jede AI sofort nutzen kann.*

| Was Sie bekommen | |
|-------------------|---|
| Discovery & Source Audit | 1–2 Tage |
| Vollständige Knowledge Base mit 7 Notiz-Typen | Snapshot, Personen, Präferenzen, Projekt-Historie, Entscheidungen, Offene Punkte, Quellen |
| Markdown-basiert — kein Vendor Lock-in | Jede AI kann damit arbeiten |
| CLAUDE.md + Ingest/Curate Skills | Läuft auf Autopilot |
| AI-Nutzungs-Guide | Prompts & Query-Patterns für echte Arbeit |
| Übergabe-Dokumentation | Wartungs-Playbook |

**Dauer:** 10–14 Tage  
**Ideal für:** KMU, die ihr wichtigstes Kunden- oder Projekt-Wissen strukturieren wollen.

*Die Knowledge Base bleibt aktuell — ohne dass Sie sich darum kümmern müssen.*

| Was Sie bekommen | |
|-------------------|---|
| Wöchentlicher Curate-Durchlauf | Vault bleibt sauber und aktuell |
| Neue Quellen werden eingebunden | E-Mails, Meetings, Dokumente |
| Priorisierter Support | Feste Ansprechperson |
| Monatliches Health-Report | Was wurde aktualisiert, was fehlt |

**Kündbar:** Ab 1 Monat  
**Empfohlen:** Für alle, die die Knowledge Base als Living Asset nutzen wollen.

## 📋 Was NICHT inklusive ist (schützt Ihre Marge)

- **Keine Custom Software Development** — das ist ein separates Projekt
- **Keine komplexen Integrationen** — API-Anbindungen jenseits von n8n/Make werden separat gescoped
- **Keine Migration aller historischen Dokumente** — Scope wird vorher definiert
- **Kein laufendes Management** — dafür gibt es den Wartungs-Retainer
